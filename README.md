1. Purpose of Creation

The School Campus Chatbot was created to act as a smart virtual assistant that helps students, teachers, parents, and visitors easily find information about the school.
Its main purpose is to make school communication faster, improve accessibility, and allow anyone to get details about departments, facilities, blocks, activities, and events through a simple chat interface.
It replaces the need to manually search or ask for information and provides instant responses 24/7.

2. Use of the Chatbot

The chatbot is mainly used for the following purposes:

To help users locate blocks, classrooms, and departments in the school.

To share important information such as timings, contact details, and facilities.

To answer frequently asked questions from students and parents.

To guide new students or visitors around the campus.

To display events, extracurricular activities, and achievements.

To reduce the workload of administrative staff by providing automated responses.

3. Features Used

The chatbot includes multiple functional and intelligent features:

Intents: Each intent recognizes a specific question or purpose from the user.

Entities: Used to identify terms such as class names, facilities, and locations.

Rich Responses: Certain responses open external actions like Google Maps.

Fallback Handling: Handles unmatched questions with helpful suggestions.

Context Awareness: Keeps track of previous messages for better continuity.

Friendly Personality: Replies in a kind, human-like, and supportive tone.

4. Advanced Features Used

The chatbot also includes advanced capabilities such as:

Google Maps Integration: When the user asks for the school address, a clickable pop-up appears, and upon clicking, the school location opens in Google Maps.

Dynamic Entity Matching: The chatbot understands different ways users phrase the same question, such as “class 5 block” or “where is primary block.”

Customized Entities: Special sets of words and meanings are created to ensure accuracy.

Multi-Topic Support: The chatbot can handle multiple topics such as games, music, or transport within the same conversation.

Interactive Design: Designed to make the conversation feel personal and natural.

6. Entities Used

The chatbot uses four types of entities to identify user keywords and respond accurately.

A. Facilities Entity

This entity contains all the school facility names and related terms.
It includes items like Chemistry Lab, Physics Lab, Biology Lab, Swimming Pool, Computer Lab, A/C and Non-A/C Classrooms, Veg Canteen, Sports Equipment, Art and Craft Room, and AV Room.

These terms allow the chatbot to recognize when users ask questions about specific facilities.

B. Location Entity

This entity is used to identify all locations and blocks within the school.
It includes values such as Kids Fun Zone, Kids Block, LKG Class, Class 11, Science Block, Class 5th, Primary Block, Admin Block, and Cafeteria.
The chatbot recognizes variations like “class 12 block,” “principal office,” or “canteen” as synonyms for these locations.

C. Name Entity

This entity includes general names and groups used in the school.
It has categories like Police, Outdoor Games, Indoor Games, and Musical Classes.
Each of these includes multiple synonyms — for example, “football,” “volleyball,” and “running race” are part of Outdoor Games; “chess” and “carrom board” are part of Indoor Games.

D. Other Entity

This entity groups other general topics.
It includes ECA (Extra Curricular Activities), Swimming, and Transport.
Each contains multiple synonyms and activity names like Karate, Dance, Judo, or School Bus.

These entities make the chatbot understand various related user inputs and reply with proper answers.

7. Overall Description

The School Campus Chatbot acts as a helpful and interactive guide within the school.
It answers location-based questions, provides information about school facilities and schedules, lists available games and activities, and even gives directions using Google Maps.
It also maintains a friendly, student-like tone so that students feel comfortable asking questions.
By automating repetitive information delivery, it reduces administrative work and ensures that all users get correct answers instantly.
